# CLI Commands

## --show

Показать список доступных проектов из конфигурации.

## upload

Создает SBOM и отправляет его в dependency track.

### Параметры

| Параметр           | Описание                                                                               |
| ------------------ | -------------------------------------------------------------------------------------- |
| --name <project> | Имя проекта. Если указано, создается и загружается SBOM только для указанного проекта. |

### Поведение по умолчанию

Если команда запускается без аргументов, создаются и загружаются SBOM для всех проектов, указанных в конфигурационном файле.

---

## sbom

Создает SBOM и возвращает путь (или список путей) к созданным файлам в каталоге sbom.

### Общие параметры

| Параметр | Описание                                  |
| -------- | ----------------------------------------- |
| --dev  | Включить анализ dev-зависимостей.         |
| --vuln | Выполнить анализ уязвимостей компонентов. |

### Источник данных

#### Локальная директория

| Параметр       | Описание                                      |
| -------------- | --------------------------------------------- |
| --dir <path> | Путь к локальной директории с исходным кодом. |

#### Git-репозиторий

| Параметр          | Описание                                          |
| ----------------- | ------------------------------------------------- |
| --repo <url>    | URL Git-репозитория для анализа.                  |
| --branch <name> | Ветка репозитория для анализа.                    |
| --clone         | Клонировать репозиторий локально в каталог src. |

#### Проект из конфигурации

| Параметр           | Описание                                                            |
| ------------------ | ------------------------------------------------------------------- |
| --name <project> | Имя проекта из JSON-конфигурации.                                   |
| --clone          | Клонировать исходный код в каталог src/<project>.                 |
| --merge          | Объединить отчеты, если проект состоит из нескольких микросервисов. |

## graph

Создает граф зависимостей для указанного пакета.

### Обязательные параметры

| Параметр              | Описание                                           |
| --------------------- | -------------------------------------------------- |
| name                | Имя пакета.                                        |
| version             | Версия пакета.                                     |
| --sbom <path>       | Путь к SBOM-файлу.                                 |

### Дополнительные параметры

| Параметр        | Описание                    |
| --------------- | --------------------------- |
| --interactive | Создать интерактивный граф. |

---

## report

Создает отчет по уязвимостям на основе SBOM.

### Параметры

| Параметр         | Описание                                                    |
| ---------------- | ----------------------------------------------------------- |
| --sbom <path>  | Путь к SBOM-файлу или каталогу с несколькими SBOM.          |
| --cvss <score> | Минимальное значение CVSS для включения уязвимости в отчет. |
